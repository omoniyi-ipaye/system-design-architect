# System Design Architect — Full Skill Bundle

This directory is the installable full System Design Architect skill bundle.

The plugin's core capability must remain usable without MCP. The optional interactive app may enhance visualization, but it must not unlock methodology or reasoning that is absent from this bundle.

Bundled content includes the governing SKILL.md plus references, templates, canonical model artifacts, examples, evaluation guidance, and helper scripts needed for the complete skill experience.
